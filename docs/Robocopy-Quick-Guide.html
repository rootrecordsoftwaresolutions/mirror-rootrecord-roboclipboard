Robocopy Quick Guide

Much faster than File Explorer for large folder copies and backups.

Robo Copy / Robo Paste (Explorer)

Installed for your Windows user account
  1. Right-click a folder → Robo Copy
  2. Go to the destination → right-click the folder (or empty space inside it) → Robo Paste
  3. Confirm → robocopy runs with multi-thread (/MT:8)

Scripts live in %LOCALAPPDATA%\RoboClipboard\. Reinstall: run Install-RoboClipboard.ps1 there.

What robocopy is

Robocopy (Robust File Copy) is a built-in Windows command-line tool. It handles huge folder trees better than Explorer: multi-threaded copy, retries, skip unchanged files, and a clear summary. Use Explorer for a few small files; use robocopy (or Robo Copy/Paste) for backups and multi-GB trees.

Command line

robocopy "C:\path\to\source" "D:\path\to\destination" /E /COPY:DAT /R:1 /W:1 /MT:8

Useful switches

SwitchMeaning
/EAll subfolders (including empty)
/MT:88 threads — usually much faster
/COPY:DATData + attributes + timestamps
/R:1 /W:11 retry, 1 second wait
/XOSkip older destination files
/MIRMirror (also deletes extras in dest — careful)
/LDry run — list only

Exit codes

0–7 = success (including “nothing new”). 8+ = failure.

Why not Explorer?

  • Explorer often stalls or fails on huge / locked trees
  • Robocopy retries and skips files already up to date
  • Multi-thread (/MT) is typically much faster
  • You get a clear summary instead of a silent hang
